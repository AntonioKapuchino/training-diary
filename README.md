# Дневник тренировок

Личный дневник тренировок для iPhone. Устанавливается с сайта как приложение (PWA), работает без интернета, все данные хранит на телефоне.

**Открыть:** https://antoniokapuchino.github.io/training-diary/ → в Safari «Поделиться» → «На экран „Домой“».

## Что умеет

- **Тренировка в зале.** Своя цифровая клавиатура: запятая на месте, кнопки «−»/«+» с шагом веса, «Далее» по ячейкам. Колонка «Прошлый раз» и серые подсказки в пустых ячейках. Галочка повторяет прошлый подход одним касанием. Подходы бывают разминочными, рабочими, дроп-сетами и до отказа; удаляются свайпом с отменой.
- **Отдых.** Таймер стартует, когда отмечаешь подход: тихий или со звуком, ±15 секунд, своё время для каждого упражнения. Экран не гаснет, пока идёт тренировка. Свёрнутая тренировка висит капсулой над вкладками, как мини-плеер.
- **Рекорды.** Расчётный разовый максимум (Эпли), максимальный вес, объём за подход, повторы, время, дистанция, темп. Отметка у подхода прямо во время тренировки и конфетти в итогах.
- **Программы.** Тренировка начинается по программе одним касанием. Программа обновляется по результату без потерь: пропущенные упражнения остаются на месте.
- **История.** Календарь месяца с группами мышц, правка любой тренировки, запись задним числом, повтор тренировки, «поделиться» текстом.
- **Прогресс.** Недели и месяцы: тренировки, объём, время. Баланс подходов по группам мышц, свежие рекорды, тренды упражнений. У каждого упражнения есть график по настоящим датам с просмотром пальцем, лучший вес на 1–10 повторов и история.
- **Тело.** Вес и обхват талии, график.
- **Данные.** Копия в «Файлы» через меню «Поделиться», таблица CSV для Excel и Numbers, загрузка копии с предпросмотром. Перед любой заменой данных и раз в неделю делается снимок на устройстве. Приложение просит браузер не удалять данные и напоминает о копии.
- **Оформление.** Как в iOS 26: крупные заголовки, стеклянные панели, тема по системе, светлая или тёмная, восемь цветов акцента.

## Переход с первой версии

При первом запуске новая версия сама переносит тренировки, свои упражнения и шаблоны из старой базы (`training-diary` в IndexedDB). Попутно убираются следы её багов: пустые дни и записи с пустой датой отбрасываются, история удалённых своих упражнений восстанавливается, дубли вроде «Подъем на носки» склеиваются со встроенным «Подъём на носки». Старая база не меняется и остаётся запасной копией. Бэкап-файлы первой версии тоже загружаются.

## Разработка

Нужны Node 24 и pnpm 11.

```bash
pnpm install
pnpm dev          # http://127.0.0.1:5173, с телефона по Wi-Fi: pnpm dev --host
pnpm verify       # типы, линтер, формат, юнит-тесты, сборка, e2e
pnpm test         # юнит-тесты (Vitest)
pnpm test:e2e     # e2e: iPhone 15 Pro (WebKit) и Pixel 7 (Chromium)
pnpm icons        # иконки из SVG в scripts/icons.ts
```

Для e2e один раз скачать браузеры: `pnpm exec playwright install webkit chromium`.

### Как устроено

```
src/
  domain/    чистая логика: типы, даты и числа по-русски, поиск с «ё», рекорды, статистика, блины
  db/        Dexie (IndexedDB): схема, каталог упражнений, операции, перенос первой версии, бэкапы
  settings/  настройки в localStorage
  ui/        компоненты в стиле iOS: страницы, списки, шторки, сегменты, графики
  features/  экраны: today, workout, history, progress, exercises, templates, settings
  app/       маршруты, каркас, таб-бар, service worker
```

React 19, TypeScript, Vite 8, Tailwind CSS 4, Motion, Dexie 4, React Router 8 (хеш-маршруты для GitHub Pages), vite-plugin-pwa. Графики — свои, на SVG.

- **Данные.** Строковые id, у упражнения ссылка на каталог, история не дублирует названия. Итоги тренировки (объём, подходы, рекорды) хранятся в кэше и пересчитываются после правок.
- **Обновления.** Новая версия скачивается в фоне и сразу берёт управление. Страница перезагружается, только когда это ничему не мешает. Если идёт тренировка или ввод, перезагрузка ждёт, пока приложение свернут. Открытый экран тренировки и таймер отдыха переживают перезагрузку.
- **Цвета групп мышц** — проверенная категориальная палитра, отдельные оттенки для светлой и тёмной темы.

### Публикация

Push в `main` запускает GitHub Actions: проверка (типы, линтер, формат, юнит- и e2e-тесты), затем сборка с `BASE_PATH=/training-diary/` и публикация на GitHub Pages. Если проверка не прошла, публикации не будет.
